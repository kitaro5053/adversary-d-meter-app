# 行動カード（手札）

行動カードは裏向きでキャラ／ボードにセットし、行動解決フェイズで全公開して解決する。
セット・解決の基本ルールは 00_rules_core.md（フェイズ2〜4）参照。**解決順は「移動 → その他」**。

## 主人公の手札（8種・各1枚）

| カード | 効果 | 備考 |
|---|---|---|
| 移動↑↓ | セットされたキャラを上下に移動 | 合成あり（下記） |
| 移動←→ | セットされたキャラを左右に移動 | 合成あり（下記） |
| 移動禁止 (1/loop) | 重なった『移動↑↓/←→/斜め』を無効化 | |
| 友好+1 | セットされたキャラに友好カウンター+1 | |
| 友好+2 (1/loop) | セットされたキャラに友好カウンター+2 | |
| 不安+1 | セットされたキャラに不安カウンター+1 | 『不安-1』と重なると**『不安+1』が先に解決** |
| 不安-1 (1/loop) | セットされたキャラから不安カウンター-1 | |
| 暗躍禁止 | 重なった『暗躍+1/+2』を無効化 | ★複数の主人公が暗躍禁止を出すと、この暗躍禁止自体が無効化される |

## 脚本家の手札（10種）

| カード | 効果 | 備考 |
|---|---|---|
| 移動↑↓ | セットされたキャラを上下に移動 | 合成あり |
| 移動←→ | セットされたキャラを左右に移動 | 合成あり |
| 移動斜め (1/loop) | セットされたキャラを斜めに移動 | 合成あり |
| 友好禁止 | 重なった『友好+1/+2』を無効化 | |
| 不安+1 | セットされたキャラに不安+1 | **このカードは脚本家手札に2枚ある**。『不安-1』と重なると『不安+1』が先 |
| 不安-1 | セットされたキャラから不安-1 | |
| 不安禁止 | 重なった『不安+1/不安-1』を無効化 | |
| 暗躍+1 | セットされたキャラまたは**ボード**に暗躍+1 | |
| 暗躍+2 (1/loop) | セットされたキャラまたは**ボード**に暗躍+2 | |

- ★ **脚本家に「不安+2」は存在しない**（不安+1が2枚）。暗躍を「+2」できるのは暗躍+2のみ。

## 移動カードの合成

同一キャラに2枚の移動カードが重なった場合、**その2枚を合わせた1枚の移動カードが出されたものとして扱う**（片方だけ解決ということはない）。

| 重なり | 結果 |
|---|---|
| 移動↑↓ ＋ 移動←→ | 移動斜め |
| 移動↑↓ ＋ 移動斜め | 移動←→ |
| 移動←→ ＋ 移動斜め | 移動↑↓ |
| 同種2枚（↑↓+↑↓ 等） | その移動が**通常通り1回**（2回移動して元の位置に戻ることはない） |

- ★ FAQ A2：神社の巫女に脚本家が移動↑↓、主人公が移動←→ → 合成＝移動斜め。だが都市は巫女の禁止エリア。**合成1枚の移動先（都市）が禁止なら、巫女は移動せず神社に留まる**（片方の移動のみ解決されることはない）。→60

## 禁止系カードの無効化

- **移動禁止**：重なった移動カード（↑↓／←→／斜め）を無効化。(1/loop)
- **暗躍禁止**：重なった暗躍+1/+2を無効化。ただし**複数の主人公が暗躍禁止を出している場合、暗躍禁止自体が無効化される**。
- **友好禁止**：重なった友好+1/+2を無効化。
- **不安禁止**：重なった不安+1／不安-1を無効化。

- ★ 暗躍禁止は**行動解決フェイズでのみ**有効。**脚本家能力フェイズ**で発動するクロマク等の暗躍は止められない（クロマクのカード「ターン終了フェイズ」表記は誤記＝正は脚本家能力フェイズ。→60: A16, →50）。

## ボードへの行動カードのセット

- ボードには**暗躍カウンターのみ**置かれる（友好・不安は不可）。ボード自体は移動しない。
- よって**ボードにセットして実際に解決されるのは**：主人公＝**暗躍禁止**のみ、脚本家＝**暗躍+1／暗躍+2**のみ。
- ★ それ以外のカードはブラフとしてボードにセットされることがある（脚本家・主人公とも）。

## 「1ループに1回まで」カードの扱い

- 解決後、手札に戻さず**表向きで持ち主の手前に置く**（使用済み＝そのループ中もう使えない）。
- 主人公手札では：移動禁止／友好+2／不安-1。脚本家手札では：移動斜め／暗躍+2。
- ★ 委員長の友好能力は「使用済みの『1ループ1回』カードを手札に戻す」もの。よって戻せる対象が手前に無いと使えない（空撃ち不可。→20, →60）。

## 補足

- 1キャラ／1ボードに同じプレイヤーが2枚以上はセット不可。脚本家のセット先には主人公が重ねられるが、他主人公のセット先には重ねられない（→00 フェイズ2-3）。
- 不安+1と不安-1が同一キャラに重なった場合、不安+1が先に解決される（差し引き0だが、解決順が誘発タイミング等に影響しうる）。
